# Hybrid Log Classifier

A small incident-intelligence service that routes application logs through the cheapest trustworthy classifier first.

## Development

This repository is being reconstructed from the project concept only. The archived repository is retained separately as historical reference.

Development is intentionally phased: foundation → rules → ML → routing → incidents → LLM fallback → API → demo → evaluation/docs → CI/security.
